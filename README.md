# Grocery-Demo

A demonstration grocery catalog and cart management application showcasing product listings, cart calculations, and inventory state management.

## Overview

- **Product Catalog**: Categorized inventory view with price, SKU, and availability.
- **Cart & Checkout Flow**: Real-time total calculation, item quantity adjustment, and order state simulation.
- **Responsive Architecture**: Clean, component-driven UI for store navigation.

## Repository Hygiene

- Dependencies (`node_modules`), build outputs (`dist`, `build`), environment credentials (`.env`), and OS metadata are strictly excluded via `.gitignore`.
